# Notas de Origem do Template

Este projeto nasceu a partir de um scaffold gerado originalmente no ecossistema Lovable, mas hoje a base operacional do desafio e local e centrada em:

- frontend React/Vite
- Supabase Functions
- modelo local via `Ollama`

As instrucoes reais de desenvolvimento e execucao vivem em [README.md](/home/tsalada/workspace/VESPAS/ctf-challenges-2026/ainjection/README.md).

## O que considerar daqui em diante

- Nao tratar este repositorio como dependente da plataforma Lovable.
- Nao assumir integracao com API externa de modelo.
- O backend principal do chat deve continuar sendo `Ollama` local.
- Se algum artefato de template conflitar com a documentacao principal, considere `README.md` como fonte de verdade.
